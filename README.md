# Система билетов для общественного транспорта

## Описание
Данный проект представляет собой симуляцию различных видов билетов для общественного транспорта. Реализованы одноразовые, безлимитные и ограниченные по поездкам билеты с возможностью их использования и пополнения.

## Классы и методы

### `Ticket`
**Описание:**  
Базовый класс для всех типов билетов.

#### `__init__(owner: str) -> None`
- **Назначение:** Создает экземпляр билета.  
- **Параметры:**
  - `owner` (str) – Имя владельца билета.  
- **Результат:** Экземпляр класса `Ticket`.

#### `off_a_trip() -> None`
- **Назначение:** Абстрактный метод для списания поездки.  

---

### `TicketArrive`
**Описание:**  
Одноразовый билет с ограниченным сроком действия.

#### `__init__(owner: str, legal_to: int) -> None`
- **Назначение:** Создает экземпляр одноразового билета.  
- **Параметры:**
  - `owner` (str) – Имя владельца билета.  
  - `legal_to` (int) – Количество дней, в течение которых билет действителен.  

#### `off_a_trip() -> None`
- **Назначение:** Списывает поездку, делая билет недействительным.

#### `__str__() -> str`
- **Назначение:** Возвращает строковое представление билета.

---

### `UnlimitedTicket`
**Описание:**  
Безлимитный билет с ограничением по сроку и балансу.

#### `__init__(owner: str, legal_to: int, account: float) -> None`
- **Назначение:** Создает экземпляр безлимитного билета.  
- **Параметры:**
  - `owner` (str) – Имя владельца билета.  
  - `legal_to` (int) – Количество дней, в течение которых билет действителен.  
  - `account` (float) – Сумма на счету билета.  

#### `off_a_trip() -> None`
- **Назначение:** Проверяет валидность билета и выводит сообщение об использовании.

#### `upAccout(cash: float) -> None`
- **Назначение:** Пополняет счет билета.

#### `__str__() -> str`
- **Назначение:** Возвращает строковое представление билета.

---

### `RestrictionsTicket`
**Описание:**  
Билет с ограничением по количеству поездок.

#### `__init__(owner: str, account: float) -> None`
- **Назначение:** Создает экземпляр ограниченного билета.  
- **Параметры:**
  - `owner` (str) – Имя владельца билета.  
  - `account` (float) – Баланс билета.  

#### `off_a_trip() -> None`
- **Назначение:** Списывает стоимость поездки со счета билета.

#### `upAccout(cash: float) -> None`
- **Назначение:** Пополняет счет билета.

#### `__str__() -> str`
- **Назначение:** Возвращает строковое представление билета.

---

### `RestrictionsTravelTicket`
**Описание:**  
Билет с ограничением по поездкам и сроку действия.

#### `__init__(owner: str, account: float, legal_to: int) -> None`
- **Назначение:** Создает экземпляр билета.  
- **Параметры:**
  - `owner` (str) – Имя владельца билета.  
  - `account` (float) – Баланс билета.  
  - `legal_to` (int) – Количество дней, в течение которых билет действителен.  

#### `off_a_trip() -> None`
- **Назначение:** Списывает поездку и проверяет срок действия билета.

#### `__str__() -> str`
- **Назначение:** Возвращает строковое представление билета.
