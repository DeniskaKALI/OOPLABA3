# Коллекция Дробей - Работа с дробными числами

## Описание
Данный проект представляет собой систему для работы с дробными числами. Реализована возможность создания дробей, выполнения арифметических операций, а также сохранения и загрузки данных в формате JSON.

## Классы и методы

### `Fraction`
**Описание:**  
Класс, реализующий дробное число и операции с ним.

#### `__init__(number: str) -> None`
- **Назначение:** Создает экземпляр дробного числа.
- **Параметры:**
  - `number` (str) – Дробь в формате строки (например, "2/6").
- **Результат:** Экземпляр класса `Fraction`.

#### `from_string(number: str) -> float`
- **Назначение:** Конвертирует строковое представление дроби в число.
- **Результат:** Возвращает дробь в виде `float`.

#### `get_numerator(number: str) -> int`
- **Назначение:** Получает числитель дроби.
- **Результат:** Возвращает числитель в формате `int`.

#### `get_denominator(number: str) -> int`
- **Назначение:** Получает знаменатель дроби.
- **Результат:** Возвращает знаменатель в формате `int`.

#### `reduce(number: str) -> str`
- **Назначение:** Сокращает дробь.
- **Результат:** Возвращает строковое представление сокращенной дроби.

#### `__add__(other: Fraction) -> Fraction`
- **Назначение:** Реализует сложение дробей.
- **Результат:** Возвращает новую дробь, являющуюся суммой двух дробей.

#### `__sub__(other: Fraction) -> Fraction`
- **Назначение:** Реализует вычитание дробей.
- **Результат:** Возвращает новую дробь, являющуюся разностью двух дробей.

#### `__mul__(other: Fraction) -> Fraction`
- **Назначение:** Реализует умножение дробей.
- **Результат:** Возвращает новую дробь, являющуюся произведением двух дробей.

#### `__floordiv__(other: Fraction) -> Fraction`
- **Назначение:** Реализует деление дробей.
- **Результат:** Возвращает новую дробь, являющуюся частным двух дробей.

#### `save(filename: str) -> None`
- **Назначение:** Сохраняет дробь в файл в формате JSON.

#### `load(filename: str) -> None`
- **Назначение:** Загружает дробь из файла в формате JSON.

---

### `FractionCollection`
**Описание:**  
Класс-контейнер для хранения дробных чисел и работы с ними.

#### `__init__(fractions: int) -> None`
- **Назначение:** Создает контейнер для дробей.
- **Параметры:**
  - `fractions` (int) – Количество дробей в коллекции.
- **Результат:** Экземпляр класса `FractionCollection`.

#### `__str__() -> str`
- **Назначение:** Возвращает строковое представление коллекции.

#### `__setitem__(number: int, data: Fraction) -> None`
- **Назначение:** Записывает дробь в коллекцию по индексу.

#### `__getitem__(number: int) -> Fraction`
- **Назначение:** Получает дробь из коллекции по индексу.

#### `add(data: Fraction) -> None`
- **Назначение:** Добавляет дробь в коллекцию.

#### `remove(index: int) -> None`
- **Назначение:** Удаляет дробь из коллекции по индексу.

#### `save(filename: str) -> None`
- **Назначение:** Сохраняет коллекцию дробей в файл JSON.

#### `load(filename: str) -> None`
- **Назначение:** Загружает коллекцию дробей из файла JSON.
