## Проект "Банковские вклады"  

Данный проект реализует систему расчета прибыли по банковским вкладам с использованием принципов объектно-ориентированного программирования (ООП): абстракции, наследования и полиморфизма. В проекте представлены три типа вкладов:  

- **TermDeposit** — срочный вклад с простыми процентами.  
- **BonusDeposit** — срочный вклад с дополнительной премией, если сумма превышает установленный порог.  
- **CapitalizedDeposit** — вклад с капитализацией процентов (сложные проценты).  

Также реализована функция `recommend_deposit`, которая подбирает наиболее выгодный вариант вклада.  

---

## Классы и их методы  

### BankDeposit (Абстрактный класс)  
Базовый класс для всех типов вкладов.  

#### Конструктор  
- **BankDeposit(principal: float, annual_rate: float, term_in_years: int)**  
  - `principal` — сумма вклада.  
  - `annual_rate` — годовая процентная ставка (0.1 = 10%).  
  - `term_in_years` — срок вклада в годах.  

#### Методы  
- **calculate_profit() -> float**  
  Абстрактный метод для расчета прибыли.  

---

### TermDeposit (Срочный вклад)  
Класс, рассчитывающий прибыль по формуле простых процентов.  

#### Методы  
- **calculate_profit() -> float**  
  Возвращает прибыль по формуле `principal * annual_rate * term_in_years`.  

---

### BonusDeposit (Бонусный вклад)  
Наследуется от `TermDeposit`, добавляет бонус при превышении порога.  

#### Конструктор  
- **BonusDeposit(principal: float, annual_rate: float, term_in_years: int, bonus_rate: float, threshold: float)**  
  - `bonus_rate` — дополнительный процент от прибыли.  
  - `threshold` — порог для получения бонуса.  

#### Методы  
- **calculate_profit() -> float**  
  Рассчитывает прибыль, добавляя бонус при превышении порога.  

---

### CapitalizedDeposit (Вклад с капитализацией)  
Рассчитывает прибыль по формуле сложных процентов.  

#### Методы  
- **calculate_profit() -> float**  
  Возвращает прибыль по формуле `principal * ((1 + annual_rate) ** term_in_years - 1)`.  

---

### recommend_deposit  
Подбирает наиболее выгодный вклад.  

#### Функция  
- **recommend_deposit(principal: float, annual_rate: float, term_in_years: int, threshold: float = 100_000.0, bonus_rate: float = 0.05) -> BankDeposit**  
  - Возвращает объект вклада с максимальной прибылью.
