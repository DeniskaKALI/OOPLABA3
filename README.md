## Проект "Змейка" с принципами ООП

Этот проект представляет собой классическую игру "Змейка" с использованием основных принципов объектно-ориентированного программирования (ООП): абстракции, наследования, инкапсуляции, полиморфизма и композиции.

### Основные классы проекта

#### gameObject (Абстрактный класс)
Определяет базовый интерфейс для всех игровых объектов.

**Методы:**
- `__init__(self, position=None)`: Инициализация объекта с заданной позицией.
- `draw(self)`: Абстрактный метод для отрисовки объекта (реализуется в наследниках).

#### Apple (Класс яблока)
Представляет собой объект, который змейка должна съесть.

**Методы:**
- `__init__(self)`: Создаёт яблоко в случайном месте.
- `randomizePosition(self)`: Перемещает яблоко в случайную позицию.
- `draw(self)`: Отрисовывает яблоко на экране.

#### Snake (Класс змейки)
Отвечает за движение, увеличение длины, обработку столкновений.

**Методы:**
- `__init__(self)`: Создаёт змейку в центре экрана.
- `reset(self)`: Сбрасывает змейку в начальное состояние.
- `updateTitle(self)`: Обновляет заголовок окна с текущей длиной змейки.
- `updateDirection(self)`: Обновляет направление движения.
- `move(self)`: Выполняет шаг вперёд, обновляя координаты змейки.
- `getHeadPosition(self)`: Возвращает текущую позицию головы змейки.
- `draw(self)`: Отрисовывает змейку на экране.

### Функции

- `handleKeys(gameObject)`: Обрабатывает ввод пользователя с клавиатуры.
- `main()`: Главная функция игры, запускает игровой цикл.

### Запуск игры

1. Установите библиотеку pygame:
   ```sh
   pip install pygame
   ```
2. Запустите скрипт:
   ```sh
   python the_snake.py
   ```

### Особенности реализации
- Игра использует принципы ООП, такие как наследование (`Apple` и `Snake` наследуются от `gameObject`).
- Обеспечена обработка столкновений и увеличение длины змейки при поедании яблок.
- Используется обновление заголовка окна с текущей длиной змейки и рекордом.
- Игровой процесс цикличен: змейка появляется с другой стороны экрана при выходе за границы.
