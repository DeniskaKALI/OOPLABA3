## Проект "Комплексные числа" с принципами ООП  

Этот проект демонстрирует работу с комплексными числами, используя основные принципы объектно-ориентированного программирования (ООП): абстракцию, инкапсуляцию, полиморфизм и композицию. В проекте реализованы следующие классы:  

- **ComplexNumber** — класс для работы с комплексными числами и выполнения базовых операций.  
- **ComplexContainer** — контейнерный класс, хранящий список объектов `ComplexNumber`.  

---

## Классы и их методы  

### ComplexNumber (Класс для работы с комплексными числами)  
Предоставляет функциональность для работы с комплексными числами, включая арифметические операции, нахождение модуля, сопряжённого числа и строкового представления.  

#### Конструктор  
- **ComplexNumber(real: float, imag: float)**  
  Создаёт объект комплексного числа с заданными действительной и мнимой частями.  

#### Методы  
- **__add__(other: ComplexNumber) -> ComplexNumber**  
  Складывает два комплексных числа и возвращает результат.  
- **mul(other: ComplexNumber) -> ComplexNumber
  Перемножает два комплексных числа.

- **truediv(other: ComplexNumber) -> ComplexNumber
  Делит одно комплексное число на другое.

- **magnitude() -> float
  Возвращает модуль (длину) комплексного числа.

- **conjugate() -> ComplexNumber
  Возвращает сопряжённое число.

- **str() -> str
  Возвращает строковое представление комплексного числа.

- **ComplexContainer (Контейнер для комплексных чисел)
  Этот класс хранит список комплексных чисел и предоставляет методы для работы с ним.

####Конструктор
- **ComplexContainer()
Создаёт пустой контейнер.
####Методы
- **add(value: ComplexNumber) -> None
  Добавляет комплексное число в контейнер.
  
- **remove(index: int) -> None
  Удаляет элемент по индексу.


- **getitem(index: int) -> ComplexNumber
  Возвращает элемент по индексу.


- **save(filename: str) -> None
  Сохраняет список комплексных чисел в JSON-файл.

- **load(filename: str) -> None
  Загружает список комплексных чисел из JSON-файла.
